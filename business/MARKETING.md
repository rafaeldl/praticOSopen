## Canal 1: ASO (App Store Optimization)

**Objetivo:** Ser encontrado nas buscas das lojas

### Keywords Alvo

| Primárias | Secundárias |
|-----------|-------------|
| ordem de serviço | app para técnico |
| OS digital | gestão de clientes |
| controle de OS | assistência técnica app |
| ordem serviço grátis | app manutenção |

### Checklist ASO

- [ ] **Nome do app:** "PraticOS - Ordem de Serviço" (keyword no nome)
- [ ] **Subtítulo (iOS):** "Gestão de OS para técnicos"
- [ ] **Descrição curta:** Incluir keywords principais
- [ ] **Descrição longa:** 
  - Primeiro parágrafo com keywords
  - Lista de funcionalidades
  - Call-to-action para download
- [ ] **Screenshots:** 
  - 5-8 screenshots com texto explicativo
  - Mostrar: OS, formulário, PDF, dashboard
  - Estilo clean, profissional
- [ ] **Vídeo preview:** 15-30s mostrando o fluxo principal
- [ ] **Ícone:** Atual está bom? Testar variações
- [ ] **Reviews:** Responder todos (positivos e negativos)

### Métricas ASO
- Posição para "ordem de serviço"
- Taxa de conversão (visualização → download)
- Nota média (meta: >4.5)
